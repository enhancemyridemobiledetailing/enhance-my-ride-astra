# Preview asset sources

The custom logo, Honda CR-V mobile rig image and detailing photographs are copied from the existing Enhance My Ride repository into this separate project.

The cinematic hero footage and its poster frames are from the public Astra Labs concept site built for Enhance My Ride. That page's credits describe the opening footage as cut from the business's own films. Original source URLs:

- https://enhancemyride.astralabs.store/assets/film/foam.mp4
- https://enhancemyride.astralabs.store/assets/film/rinse.mp4
- https://enhancemyride.astralabs.store/assets/film/finish.mp4
- https://enhancemyride.astralabs.store/assets/film/hero-phone.mp4

Poster frames use the same names with `.jpg` extensions. These assets are included only in this separate preview project; the original repository and production domain were not changed.
